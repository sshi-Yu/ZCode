## Context

GenImage 当前作为 MCP App 绑定聊天会话，画布状态存在页面内存。已确认 ZCode 支持 `scope: "app"` 的无会话扩展视图，宿主也有一级主区导航。第一版将交付独立安装的 GenImage 画布、桌面一级「生图」入口、模型配置和从生成到恢复的完整流程，并使用本地供应商夹具在开发版验证同一条执行链。

## 实施

1. **先更新规格和桌面验收。** 将 `docs/superpowers/specs/2026-11-23-genimage-plugin-design.md` 中的所有权、模型配置、生成时序和首版验收更新为应用级契约，保留既有键盘回归。同步更新插件用例目录及覆盖状态，在实现前补齐桌面候选用例。执行改动前架构检查，读取 `extension-slots`、`extensions-service` 和目标宿主模块的架构上下文。Plan Mode 已拦截架构命令，将在解除只读后执行。
2. **宿主导航与插件产物。** 在 `ProjectSidebarNavigation.tsx`、`App.tsx`、`WorkspaceShellLayout.tsx` 的现有一级视图接线中增加「生图」。按已安装的 GenImage 扩展视图打开 App 作用域沙箱，沿用 `extensionViewPage.ts` 和 `IExtensionViewsService`，用包好的 React 画布验证可见性和启停。缺失、停用或未就绪时显示相应入口或状态。`plugins/apps/genimage` 增加扩展入口及市场打包，保留现有 MCP 入口及其打开语义。主区无选中会话可打开，切换本地项目或远端项目仍访问同一本地画布。
3. **本地模型配置。** 在 `SettingsPage.tsx` 注入本地服务的「模型配置」内增加独立生图区，首版提供一个 OpenAI Images 文生图适配器及适配器支持的模型。生图设置由本地 Host 保存，复用宿主凭据服务保存 Key，界面只读到配置状态。先使用固定 HTTPS 生产目的地及适配器支持的模型，按宿主网络传输调用。测试通过专用夹具注入回环端点。聊天模型目录、默认值和远端配置按原有边界运行。检查无聊天会话及未配置生图模型的入口，已有宿主登录流程按现行合同处理。
4. **生成和恢复。** 在受控 Host 模块中定义桌面本地服务与窄契约。主区画布通过已绑定实例的 AppBridge 提交明确的生图意图或读取投影，生成命令只由宿主确认界面发起，确认面向同一份模型与提示词参数。通用扩展能力网关沿用现有授权行为。Host 校验配置后按请求 ID 持久受理，原子更新活动任务，单次发送供应商请求，校验图片并落盘，提交成功后发布历史和资产。复用应用数据目录、图像和文件保存能力。首版一份本地画布、单图文生图和原图导出。失败或结果未知有明确状态。重启恢复已保存内容，可能已发出的请求有持久围栏，重开视图只读回状态。

```text
本地模型配置 ──→ Host 生图配置与凭据
GenImage 画布 ──→ 宿主确认 ──→ Host 受理并持久记录 ──→ 生图接口
      ↑                      │                       │
      └──── 读取任务与图片 ────┴── 本地图像与历史 ←──────┘
```

## 验证

- 在隔离桌面开发版以真实市场产物安装 GenImage。验证无会话打开主区、主题和键盘操作、切换聊天与项目后打开同一画布、插件重载和完整重启后恢复作品。
- 通过桌面界面从模型配置到生成与导出。使用记录请求次数和模型 ID 的回环夹具，验证未配置、取消确认、重复提交、接口失败及结果未知时的实际请求数与 UI 状态，同时检查聊天默认模型隔离。以导出字节一致性证明从请求到文件交付。
- 运行 GenImage 包的类型检查、构建产物冒烟和浏览器回归、相关桌面 E2E、根 `pnpm typecheck`、`pnpm lint`、架构检查及 `git diff --check`。复核新增 React hooks 诊断，按实际验证层级报告。付费调用需要另有明确授权，本轮以夹具覆盖生产实现链路。
