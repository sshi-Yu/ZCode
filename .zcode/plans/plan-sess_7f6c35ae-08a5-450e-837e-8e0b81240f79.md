## Context

当前 NextStep 是横向按钮组，首次读取时组件隐藏，刷新等待也缺少明确反馈。本次将它改成轻量的纵向推荐列表，显示 2–4 条，按概述（当前 `label`）字符数从短到长排列，并完善图标、加载反馈和动效。

## 界面与交互

采用紧凑单列，限制最大宽度、窄窗口内自适应。每行左侧为维度图标，右侧为概述；统一左对齐、允许长文换行。列表上方用一行淡色标题「下一步建议」，刷新按钮放在该行右侧，与列表整体对齐。

```text
下一步建议                           ↻
┌─────────────────────────────────────┐
│ ◇ 较短的概述                        │
│ ⌕ 稍长一些的概述                    │
│ ✎ 更完整、更长的推进概述            │
└─────────────────────────────────────┘
```

- 推荐行使用现有 Button、Tooltip 和主题语义色；可点击时显示 pointer，悬浮加深背景、文字和图标，按下轻微反馈，保留可见键盘焦点和完整提示词预览。
- 图标根据 `dimension` 做本地语义映射，覆盖分析、深化、扩展、写作、修改、验证、实施等中英文维度；未知维度使用统一的探索图标。不增加模型调用，也不接受插件提供 SVG 或样式。
- 首次读取展示「正在读取推荐…」及轻量占位；手动生成/刷新点击后立即显示「正在生成推荐…」和旋转进度。通知引起的后台读取保留当前布局，用小进度提示反馈，避免整块反复消失。
- 刷新受理进入新版本后，用加载状态替换旧选项，避免旧建议看起来仍属于最新版本。生成失败、未知、无建议和读取失败继续明确区分，提供对应操作。
- 淡入和约 4px 位移在 180–220ms 内完成，推荐行使用约 30ms 的小幅错峰；hover/按下过渡约 120–150ms。不加弹跳或大面积循环动效。遵循 `prefers-reduced-motion`，关闭位移、错峰及旋转后仍保留文字状态。

## 数据与兼容

- NextStep 新生成结果收敛为 2–4 条：修改提示词，合法候选去重后按 `Array.from(label.trim()).length` 稳定排序，最多保留 4 条；相同长度保持原顺序。仍使用单次模型请求，不做格式修复再调用。
- 既有缓存可能包含 5 条。保留通用传输契约对旧数据的读取兼容，展示时排序后取前 4 条；不改写 SQLite 历史，不改变 ID、version、revision，不自动刷新。点击仍提交原建议 ID 和原版本。
- `useTurnFooterSlot` 继续独占临时展示状态，显式区分读取、刷新受理和提交等待。保留先订阅后读取、版本/revision 水位、切换目标后丢弃旧响应的规则。Host 的 `unavailable` 仍隐藏插槽；Web、远控及不合格会话继续不展示。

```text
读取/用户点击 → useTurnFooterSlot 的临时等待状态 → 原有 Host 请求
                                              ↓
插件持久版本 → 失效通知 → 只读最新版本 → 排序展示 / 状态过渡
```
