# 图像模型与小工具模型

## 用户界面与范围

- 在模型设置双栏导航的供应商组下方新增「图像」。小工具模型直接在现有供应商的模型行设置，两项配置由本机桌面 Host 提供。
- 图像组保存多个生图配置，并允许选定默认配置。每项包含显示名称、模型 ID、协议、Base URL、Bearer Key、可选尺寸与质量。OpenAI GPT Image 使用 `POST /v1/images/generations` 的 JSON 请求与 `data[].b64_json` 响应，省略传统 `response_format`。截图所示的兼容站使用同一路径、固定 `n=1`、同步 Base64，只允许 `model`、`prompt`、`n`、`size`、`quality` 和可选的 `response_format: b64_json`。两者在配置中显式区分。Base URL 可含路径前缀或 `/v1`，请求预览只追加一次 `/v1/images/generations`。
- 此轮交付图像配置，GenImage 画布仍使用自己的本地 SVG 示例。打开、保存配置、切换默认项均不会发出图像请求。异步图片任务、参考图、真实生成和试生成属于后续对接。
- 生图详情使用与供应商一致的输入框和应用内下拉菜单。表单按模型信息、接口连接和可选生成参数分组；请求地址置于 Base URL 下方，窄面板内按单列布局。
- 每台设备可标记一个已保存且支持文本输入和输出的模型，包括还没填密钥或暂未启用的自定义模型。在模型行点击扳手可设置或取消标记，再标记另一个模型会替换前一个。按钮以按下状态表达当前标记。标记不修改聊天模型选择、供应商配置或模型启用状态。
- 设置服务只保存标记和解析可用模型。Git 提交说明通过自己的现有生成入口读取标记，未标记或标记不可用时使用当前会话有效模型，无会话的入口仍沿用环境默认。后续插件可在自身的调用边界复用 Host 解析接口，并保留各自的权限和会话回退规则。

## 所有权与调用路径

```text
模型设置 Renderer → 本机 Desktop attachment → 模型设置服务
  图像表单 → 校验协议与 HTTPS 目的地 → 加密凭据 + 本地配置文件
  模型行标记 → 复核本机 Provider Settings 文本模型 → 写入唯一小工具模型标记
Git 生成 → Host 在可执行 Model Selection 中解析标记 → 未命中则回退到当前会话模型
```

- Host 的单一 JSON 配置采用文件锁和原子替换。图像配置和小工具模型各自维护修订号。同类配置并发保存遇到修订冲突时要求刷新。
- 图片密钥使用 Host 私有的独立键。读取只返回是否配置。换目的地时要求重新录入密钥，配置成功后才回收旧键。凭据的通用 RPC 禁止访问该私有前缀。设置附件、远端工作区代理及手机附件不发布该模型设置服务。
- 旧 Git 专用绑定不会迁移为跨工具的标记。旧配置文件中的图像配置仍可读取。工具模型按调用时的运行环境解析，远端工作区使用自己的会话选择。

## 验收

1. 桌面打开模型设置，图像入口和现有供应商可相互切换。
2. 使用应用内下拉菜单选择协议和质量，保存 OpenAI 与 Base64 配置，切换默认配置，关闭重开后保留；密钥字段保持空白且投影只返回状态。
3. 在缺少 API Key 的自定义供应商模型行设置标记、更换标记和取消标记。重启后显示唯一保存的标记；运行时不调用当前不可执行的标记模型。
4. Git 生成使用标记模型。取消标记后再次生成使用原会话模型。两次显式生成都只回填草稿。
