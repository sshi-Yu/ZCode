# 图像：本机画布与大屏预览

当前切片与素材、模型和持久化规则见[图像画布产品与技术设计](./2026-11-27-genimage-canvas-product-design.md)。内置页面不改变独立插件；内部 `genimage` 标识保留，用户可见名称为「图像」。

## 入口与边界

- 左侧主导航新增「图像」。仅普通 Electron 桌面窗口显示；无须插件、登录或活动会话。普通 Web 和手机远控不显示。选择桌面远程项目并不会为它启动远程图像连接。
- Shell 的主视图状态决定进入和离开。画布占据主内容区，不展示聊天工具条、终端或聊天右栏；保留项目导航与系统窗口控件。返回聊天沿用之前的会话，不创建任务或发送消息。
- Host 保存节点、坐标和素材，画布页面持有相机、选中项、浮层及未提交提示词。打开直接读取当前本机画布，无模拟模式或临时 SVG 示例；空画布显示「创建图像」和「导入素材」。主题和语言继承应用。

## 视图与事件

- 保留点阵背景、缩放/聚焦、可拖卡片、来源箭头，以及历史、设置、详情、帮助和创建图像表单。宽视口右侧浮层，窄视口使用可滚动底部浮层，依据画布容器宽度定位。
- 提交非空提示词并成功收到图像，或导入本地图片，均追加一个缓存节点。首版不提供派生操作。拖动只改坐标；历史与已有关系链接可聚焦。选中卡片可打开预览，卡片展示最多三个已提取标签，不放完整描述。
- 派生连线从两张卡片相向的边缘出入。横向有空间时优先使用左右边缘，横向重叠而纵向分离时使用上下边缘；卡片互相遮挡时暂不绘制该段。曲线在选定轴上不回折，箭头为与线同色的空心尖角，随直接谱系高亮，缩放时保持细线和可辨识的箭头尺寸。
- 设置展示本机画布归属、图像生成模型和特征提取模型状态。素材和画布只保存在本机，不经远程/手机同步。

## 大屏预览

- 默认以窗口内全屏对话框打开原图，适应视口、不拉伸或裁切。用中性背景衬托图片；顶栏显示文件名、真实像素尺寸和关闭按钮，并避开桌面窗口控件；底栏提供缩放、适应窗口和导出原图。
- 复用现有预览缩放和平移能力，不引入图库依赖。不显示聊天标注或添加附件动作。图片加载失败在预览内提示，仍可关闭；点击预览控件和放大后拖动不会触发关闭。
- 「图像特征」默认收起。宽窗口在右侧展开，窄窗口在底部展开；显示完整摘要、标签、模型和来源。显式提取前说明接收方；打开预览或展开详情不发送图片。关闭预览时恢复触发点焦点，不改变画布相机和选中图。

```text
左侧「图像」→ Shell → 本机画布 → Host 快照和缩略图
                   ├─ 导入素材 / 创建图像 → Host 发布新节点
                   └─ 打开卡片 → 大屏原图 → 按需查看或提取特征
```

## 验收

`GENIMAGE-VIEW`：桌面从会话外打开「图像」，没有模拟开关和示例；导入后能拖动、缩放和通过历史定位；大屏在宽窄窗口和两种主题下可用，`Esc` 恢复焦点；回到聊天不发消息，再进入恢复已保存节点。
