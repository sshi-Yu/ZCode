# GenImage 内置画布：视图切片

以已确认的 `plugins/apps/genimage` 预览及其截图为交互基线。这个切片不是此前生图服务方案的恢复，不改变现有插件或其独立预览。

下文描述默认的 SVG 快速预览。桌面可另外从画布右下角进入可恢复、可导出的「本机模拟」，见 [本机画布实施计划](../plans/2026-11-27-genimage-local-canvas.md)。

## 入口与边界

- 左侧主导航新增 `GenImage`。仅普通 Electron 桌面窗口显示；无须插件、登录或活动会话。普通 Web 和手机远控不显示。选择桌面远程项目并不会为它启动远程生图连接。
- Shell 的主视图状态决定进入和离开。画布占据主内容区，不展示聊天工具条、终端或聊天右栏；保留项目导航与系统窗口控件。返回聊天沿用之前的会话，不创建任务或发送消息。
- 画布页面唯一持有节点、相机、选中项、浮层、提示词和比例。打开以三张本地 SVG 示例开始，A 是根，B 和 C 派生自 A；退出页面或重载即重置。主题和语言继承应用；首轮提供中英文。

## 视图与事件

- 保留点阵背景、缩放/聚焦、可拖卡片、来源箭头、选中卡片动作和浮动历史、设置、详情、帮助、新建/派生表单。宽视口右侧浮层，窄视口使用可滚动底部浮层。浮层基于画布容器宽度定位，不以整个窗口宽度判断。
- 提交非空提示词仅追加一张 SVG 示例；新建无父图，派生固定引用所选源图。不修改源图。拖动不改谱系，历史与关系链接可聚焦。Esc 关闭浮层并尝试还原焦点。
- 设置只展示本地模拟状态；导出与引用保持禁用。无请求、供应商、凭据、数据库、文件写入、MCP 或工作区持久化。原插件不修改、旧插件不迁移。

```text
左侧导航 → Shell 主视图
             └─ 原生 Canvas：提示词 / 比例 / 来源 → 追加 SVG 节点 → 派生连线、历史
                └─ 拖动、缩放和定位仅改变视图投影
```

## 验收

`GENIMAGE-VIEW`：桌面从会话外打开原生画布，样例节点和谱系完整；派生时留下来源节点，历史可定位；拖拽和缩放不改来源；窄宽与两种主题下浮层可用；离开后可返回聊天，再打开重置。不以此证明真实生图、文件导出或跨端恢复。
