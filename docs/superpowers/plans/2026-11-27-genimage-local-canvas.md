# GenImage 本机画布实施计划

**目标** 为原生画布增加可明确进入的本机模拟模式。使用者可生成、单图派生、拖动、定位历史、重开恢复、预览和导出。

**边界** 本轮使用一个本机模拟适配器。正式供应商仍由既有模型配置管理。原生 SVG 样例仍作为快速交互预览。模拟素材、历史和布局保存到相互隔离的本机项目或个人画布。

1. 先扩展桌面 pending E2E，验证模拟入口、A → B/C → D、位置持久化、退出后重进及应用重启、原图预览和导出。保留已有 SVG 预览用例。
2. 增加 GenImage 公共契约、本机持久任务 owner 与受控媒体读取。`scope` 取本机工作区身份，空值代表个人画布。`requestId` 幂等受理，位置写入校验节点版本。使用短事务或文件锁，确保多窗口共享事实。生成任务、素材和布局均由本机服务保存。
3. 将服务注册到本机桌面 attachment。Shell 提供工作区归属，远程工作区只可显式进入个人画布。视图复用原有节点、候选表单、关系与历史控件。平台负责选文件和保存。
4. 执行定向桌面 E2E、类型、Lint 及架构检查。用报告记录对重启、导出、隔离和重复提交的直接证据。

```text
用户打开模拟 → Renderer 读取所选画布 → 本机 Host 读取已保存状态
点击生成 → Host 受理并记录 requestId → 本机模拟输出 → 发布素材和关系 → 返回新快照
再次打开 → 读取相同 scope 的快照 → 恢复节点、坐标与关系
```

同步模拟只在一次受理内执行。Host 在原图与缩略图完整发布后才把节点投影为成图。调用断开后通过相同 ID 或读取画布恢复。真实接口的异步队列、租约与上游费用不确定状态在对应接入阶段实施。

预览只向 Renderer 提供 Host 按画布和节点授权的素材 URL。原图导出由用户主动发起，用同一范围校验读取有界 PNG 字节，再交给桌面原生保存对话框。
