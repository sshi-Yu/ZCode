# 图像画布视图

桌面 Shell 提供本机 `localScope`、显示名称和可选窗口控件。空字符串对应个人画布。视图通过 hooks 读取 Host 快照和专用模型设置，自己管理相机、选中状态和创作草稿。

「导入素材」支持多选，成功项直接排列在当前可见区域。加载画布时从 Host 恢复节点和布局。拖动结束或键盘微移时提交坐标与预期版本。

「创建图像」显示图像生成模型的接收域名、模型 ID、尺寸和质量。提交携带配置修订。发送失败后原提交沿用同一个 `requestId`，新请求要单独确认。已创建图像在结果到达时保留用户当前相机，首图超出可见范围时重新取景。

图卡展示缩略图、名称和最多三个特征标签。打开全窗预览时用授权 URL 加载原图，复用只读缩放、拖动和手势，关闭后还原焦点。特征面板展开后展示完整结果和提取目的地，由用户显式发起提取。导出通过平台保存对话框保存 Host 缓存的原始字节。

交互和验收场景见[画布规格](../../../../docs/superpowers/specs/2026-11-27-genimage-canvas-product-design.md)。
