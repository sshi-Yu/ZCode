# 图像画布服务

本机 Host 拥有每个画布的节点、任务、素材和特征。空 scope 对应个人画布，有值时使用本机工作区身份。服务拒绝远程工作区身份，使用 scope 摘要定位 `genimage/live` 下的真实画布。节点、原图和缩略图都按画布授权。

```text
导入 → 解码并生成缩略图 → 短锁发布两份文件并提交节点
创建图像 → 短锁保存请求 → 解锁执行同步模型调用 → 短锁提交结果
提取特征 → 短锁核对模型修订、有效路由和素材 → 查缓存或占用
         → 解锁后由 CLI 再核对路由并发送 PNG 副本 → 短锁确认仍可提交 → 保存摘要及标签
拖动 → 短锁校验节点版本 → 提交坐标
预览与导出 → 校验节点归属和文件摘要 → 授权本机 URL 或读取原始字节
```

单画布最多 500 个节点。导入支持 PNG、JPEG，原图最多 16 MiB，边长最多 4096 像素。同步图像生成接受一张 PNG。原始文件字节与不含元数据的 PNG 缩略图分别缓存，缩略图最长边 240 像素。发布以原子替换清单为提交点，后续在同一个锁内回收未提交文件。

创建和导入以调用方提供的小写 UUID 为 `requestId`。参数与 ID 相同的重复调用返回已提交快照。同步生成先写入请求，同一个 ID 在跨进程或重启后仍只允许一次发送。拖动使用节点版本控制并发。

特征结果和在途占用按画布、原图摘要、模型修订与有效路由区分。修改模型或端点后保留原有摘要与标签，显式重新提取成功后更新。失败释放占用并保留原结果，中断由租约回收。`resolveModel`、`resolveFeatureModel`、`generateImage` 和 `extractImageFeatures` 仅用于本机 Host 装配。
