# GenImage 本机画布服务

本机 Host 拥有画布快照、生成记录和 PNG 素材。`scope` 由调用方提供本机工作区身份，空字符串代表个人画布。服务拒绝远程工作区身份，按 scope 的 SHA-256 将数据放进各自的目录。派生源、预览和导出素材均须属于调用指定的画布。

```text
生成 → 画布文件锁 → 读取快照并查重 → 生成并发布两份 PNG → 原子替换清单 → 返回快照
拖动 → 同一把文件锁 → 校验节点版本 → 原子替换清单 → 返回快照
预览 → 从已提交快照确认节点归属 → 校验指定 PNG → 注册预览 URL
导出 → 从已提交快照确认节点归属 → 校验原图 PNG → 返回原图字节
```

清单记录已完成的生成。以清单替换为提交点，重启或并发窗口从同一份清单恢复。调用方使用小写 UUID 作为 `requestId`，成图节点沿用该 ID。相同 `requestId` 和相同归一化参数返回最新画布快照，参数不同则拒绝。提示词去掉首尾空白，坐标保持调用方提供的精度。生成使画布修订号加一，新节点版本从一开始。拖动需要匹配节点版本，成功后修订号和节点版本各加一。两份图片均发布后才提交节点。后续写入在同一把锁内清理此前中断遗留的临时文件和未提交素材。

单画布最多 500 个节点，提示词最多 4,000 个 UTF-16 代码单元，坐标绝对值最多 1,000,000。模拟原图最长边 768 像素，缩略图最长边 320 像素，每份文件分别限 2 MiB 和 256 KiB。派生根据源图内容生成局部变化。图片由本机计算，服务在返回预览 URL 前校验文件大小及摘要。

发布时先刷写临时文件，再在同一目录原子重命名。支持目录刷写的平台也会同步目录项。Windows 使用文件刷写和原子重命名恢复 Host 进程中断。
